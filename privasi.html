Kebijakan Privasi Fintatif Home

Berlaku sejak 4 November 2026

Data akun

Saat mendaftar, kami menyimpan nama, alamat email, sandi yang terenkripsi, nominal transfer, status pembayaran, dan tanggal pendaftaran di database Fintatif.

Catatan keuangan kalian

Transaksi, amplop, tagihan, impian, harta, utang, catatan obrolan, dan foto profil tidak dikirim ke server Fintatif. Data itu disimpan di browser perangkat kalian dan di Google Sheet yang dibuat di Google Drive akun kalian sendiri. File itu tidak dibagikan ke Fintatif, jadi Fintatif tidak bisa membukanya.

Kenapa harus menyambungkan Google

Dua HP kalian tersambung lewat satu Google Sheet, jadi sambungan Google wajib untuk memakai aplikasi ini. Aplikasi meminta izin Google Drive drive.file. Dengan izin ini aplikasi hanya bisa membuat dan mengubah file buku kasnya sendiri, atau file pasangan yang kalian buka lewat tautan undangan. Aplikasi tidak bisa membuka file lain di Drive kalian.

  • Data dikirim langsung dari browser kalian ke Google, tidak melewati server Fintatif.
  • Izin Google (token akses yang berlaku sekitar 1 jam) dan alamat akun Google yang dipilih hanya disimpan di browser perangkat kalian. Izin itu diperpanjang otomatis, langsung antara browser kalian dan Google.
  • Keluar dari akun menghapus izin itu dari perangkat. Akses juga bisa dicabut kapan saja di pengaturan izin akun Google.
  • Kami tidak menjual, membagikan, atau memakai data dari Google untuk iklan, dan tidak memakainya untuk melatih model kecerdasan buatan.
  • File di Google Drive tetap milik kalian dan bisa dihapus kapan saja.

Penggunaan dan pemindahan informasi yang diterima Fintatif Home dari Google API mematuhi Google API Services User Data Policy, termasuk ketentuan Limited Use.

Yang terlihat oleh pasangan

Karena file-nya sama, semua yang dicatat di aplikasi bisa dilihat kalian berdua. Untuk uang yang ingin tetap pribadi, pakai Jatah pribadi: yang tercatat hanya jumlah yang cair.

Berbagi ke pasangan

Saat kalian menekan Ajak pasangan, aplikasi membagikan file ke alamat email yang kalian ketik dengan akses edit. Akses itu bisa dicabut kapan saja dari Google Drive.

Email yang kami kirim

Kami mengirim email aktivasi setelah pembayaran terverifikasi, dan kode untuk membuat password baru kalau kalian memintanya.

Keamanan

Semua koneksi memakai HTTPS. Password dan sesi masuk terenkripsi.

Menghapus data

Kalian bisa menghapus file langsung dari Google Drive, menghapus data di perangkat dengan keluar dari akun, dan mencabut akses aplikasi di myaccount.google.com/permissions. Untuk menghapus data akun pendaftaran, kirim email ke kami.
